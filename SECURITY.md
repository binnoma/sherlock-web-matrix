# Security Policy

## Responsible Disclosure
This project is an open-source OSINT intelligence reconnaissance framework designed for:
- Self-assessment of digital footprints.
- Authorized cybersecurity audits and defensive intelligence.

If you discover a security vulnerability or sensitive leak within this tool:
1. Please report it privately by contacting **@binnoma** via [binnoma.com](https://binnoma.com) or opening a private advisory on GitHub.
2. Provide actionable steps and details to reproduce the issue.
3. Allow reasonable time for remediation before any public disclosure.

## Disclaimer
The authors and contributors assume no liability for misuse. Users are solely responsible for ensuring compliance with applicable privacy and data protection laws in their jurisdiction.
