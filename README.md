3. **تصدير تقرير استخباراتي أمني رسمي (PDF Dossier):**
   - زر لتوليد وطباعة تقرير رسمي منظم بصيغة PDF يحتوي على مستوى التعرض الرقمي، بيانات الهدف، وجدول كامل بجميع الروابط والحسابات المكتشفة.
4. **سجل الفحوصات والذاكرة التاريخية (Investigation History):**

5. **فتح جميع الحسابات بنقرة واحدة (Open All Profiles):**
   - زر لفتح كافة الروابط المكتشفة في تبويبات متصفح جديدة تلقائياً لتسريع الفحص والتحقق.
6. **جلب شعارات المواقع والصور الرمزية (Favicon Scraper):**
   - ظهور أيقونات وشعارات المنصات الحقيقية داخل بطاقات الحسابات تلقائياً.
7. **نظام الفرز المتسلسل الذكي (Two-Phase Pipeline):**
   - فحص شبكات التواصل الاجتماعي أولاً لإظهار النتائج في ثوانٍ، ثم الانتقال التلقائي للفحص الشامل (3,025+ موقع).
- **بث مباشر وفوري (Live Streaming):** ظهور الحسابات والروابط لحظة بلحظة أثناء الفحص دون انتظار.
- **فحص سريع لأشهر المواقع:** خيار للبحث في أهم 15 منصة خلال ثوانٍ معدودة.
- **تصدير النتائج:** تنزيل تقرير بضغطة زر بصيغة CSV أو JSON.

## 本环境的两处特殊性（已处理）
1. **远程站点库不可达**：程序启动时默认会请求 `https://data.sherlockproject.xyz` 更新站点数据，在本网络下 30 秒超时失败。因此 `run.sh` 固定加 `--local`，使用仓库内置的 `sherlock_project/resources/data.json`。
2. **版本检查告警**：启动时出现 `A problem occurred while checking for an update: 'tag_name'`，属 GitHub API 不可达导致的非致命告警，不影响扫描。

## 结果可信度（实测结论，务必注意）
以 `torvalds` 为样例跑全量 481 站点，命中 82 条，但抽查发现存在明显假阳性：
- `dribbble.com/torvalds` 直接请求返回 **404**，工具却判为存在；
- `bitbucket.org/torvalds/`、`codeberg.org/torvalds` 返回 200 但页面内容需人工复核；
- 部分站点（Apple Discussions、Airliners 等）对任意用户名都返回 200 或 202，属"软 404"。

**结论：工具只能用于"初筛"，每条命中都必须人工打开链接确认。** 0.16.x 的降噪机制降低了误报，但没有消除。
