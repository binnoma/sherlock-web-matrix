# Contributing to Sherlock Cyber Recon Matrix

Thank you for your interest in improving this project!

## How to Contribute
1. **Fork the Repository:** Create your own branch from `main`.
2. **Add New Platforms or Features:** Test site definitions or enhancements locally before submitting.
3. **Follow Code Conventions:**
   - Keep scripts modular and cleanly formatted.
   - Test async performance and rate limits.
   - Maintain bilingual support across Arabic and English interfaces.
4. **Submit a Pull Request:** Explain the scope of your changes and benefits clearly.

For questions, reach out to **@binnoma** via [binnoma.com](https://binnoma.com).
